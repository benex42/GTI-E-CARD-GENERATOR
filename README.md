# GTI E-Card Generator

This is a Next.js application. It must be run or deployed as a Next.js project, rather than opened with a static Live Server.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production check, run `npm run build` and then `npm start`.

The development server uses Next.js Fast Refresh, so saved changes appear in the browser automatically. In VS Code, opening this folder starts `npm run dev` through the included workspace task.
